Baseline: `beb7516b`. Scope: 37 files, 756 source test declarations, 791 expanded runtime cases in the baseline; all 791 passed. Parameterized declarations retain their literal template names below and apply to every explicit data row in their source. Source line references refer to the baseline.

## Changes and protection

- Drop two intermediate slimmer wrapper tests and their local `assertCapped` helper. API `agent-chat/slim.test.ts` independently owns UTF-8/Unicode limits. Public snapshot behavior remains in `orchestration/fix-wave.test.ts`; public reconnect behavior remains in `orchestration/v1-residual.test.ts`, including truncation flags and full persisted data.
- Consolidate three file-backed launch roundtrips into one fresh-store reread that includes credentials, unset env, home, keyed server env and profile, retaining literal mode `0600`. Move direct parser shape cases into the persisted unreadable-profile owner; roundtrip its unreadable marker once instead of repeating the identical persistence check for every invalid input. The parser remains exported: it has production callers in launch-profile/orchestrator.
- Remove resolved-request trimming with a later request: ordinary old-turn trimming plus the retained sole-request/tombstone case protect the same behavior, with the latter catching the meaningful phantom-pending regression.
- Use 1001 instead of 1200 replay rows to cross the 1000-row public replay budget; use 20 instead of 900 prompt context lines to cross the 180-character preview limit while retaining literal whitespace/description expectations. Exact 32000-character and Unicode prompt-boundary cases remain.
- Remove incidental exact 'Switched to Global' notice copy. The event, profile identity, persisted launch, next provider launch and resume cursor remain checked.
- Deliberately retain the profile identity policy test: its revision-only change keeps the same prepared directory. A refresh test that changes both revision and directory cannot catch omission of revision from the identity key.

No fixture/snapshot/dependency/configuration removals were enabled by these changes. Only unused local test helper/imports disappear. No timing threshold/retry is raised, no meaningful gate is skipped, and no mutable infrastructure is shared.

## Six-part retention evidence

Every case below names its exact promised outcome and provides an oracle example. The per-file evidence applies to each KEEP and surviving REWRITE/OPTIMIZE/CONSOLIDATE row:

1. **Independent contract:** cited design/API/security/incident source, checked against its current production owner.
2. **Real regression:** the case's input/state violating its named promised outcome yields the user/caller failure class listed for the file.
3. **Independent oracle:** hand-authored fixture values, literal states/codes/identifiers, expected output data, deadlines or file mode; never an expected result computed by the production function under test. Roundtrip identity is the independently specified persistence guarantee.
4. **Stable seam:** named public host/store/adapter/protocol boundary or the lowest pure policy/converter owner of its public data contract. Fakes isolate provider/process dependencies; they do not implement the host/converter behavior asserted.
5. **Refactor resistance:** assertions observe emitted/persisted data, commands accepted/refused, adapter protocol inputs or projection results. The explicit no-read replay contract permits observing the stable storage interface.
6. **Unique protection:** the file's owner split is described below; each retained case names a different meaningful input/state/transition within it. Adapter, fold and wire tests are retained only when they can fail independently at different assembly boundaries.
