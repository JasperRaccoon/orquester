Exact incoming source `610d3c53b480dcfe71ff45f14ce59b6df29f8bf8`. Scope: all18 root-level device test files, **112 original cases**; Android/toolchain/hosts separately owned. Every exact original path/name/line and all six criteria are recorded in the JSON companion.

Current final source: **101 cases**, test LOC **-200** against610d. Dispositions: REWRITE 34, CONSOLIDATE 6, KEEP 63, OPTIMIZE 4, DELETE 5. Runtime validation is pending.

## Safety and independent contracts

- Read device module map and all3 approved phase specs, every112 root test case and production boundary relevant to each.
- All root factory/host/action dependencies are fakes; no real rentals, SDK installs, emulators or live appdir.
- Only real temporary Node CLI children, actual image Worker threads and random loopback HTTP/WebSocket servers run. Teardown stops services/processes/workers and removes private tempdirs.
- An arbitrary50ms cancellation sleep was replaced with actual child-ready filesystem receipt. Nine-minute open deadline now uses virtual clocks and gated external boot; no real nine-minute wait.

The approved core/fleet/research specs and captured agent-device0.21.31 frames supply independent contracts. Critical approval, caps, principal/lease isolation, control, secrets, realpath containment and persistent compatibility survive at real public service/wire/store boundaries. Pure decidePool tests stay because the fleet spec explicitly defines that scheduler decision port.

## Cleanup and resource costs

- actions.ts: internalized7 helper functions and PlanContext export after exercising their meaningful outcomes through public executor
- agent-device.ts: internalized argv/env/parser/path-redaction exports; real process/error boundaries own privacy/protocol
- action-log.ts: removed custom id/limit options; real200-row public limit tested
- pool.ts: internalized Android hard-cap/start-estimate constants; expectations use independent16/30 literals, settings factory supplied by config productionowner
- service.ts: removed openWaitMs injection; Android integration owner removes manual override (coordinated)
- store.ts: removed unused loaded bookkeeping surface
- mjpeg-still-frame.ts: internalized tracker; removed custom delay argument, virtual clocks test production timer
- images: separate delegated result records removed pool constructor knobs/stats and thumbnail mock/cache overrides

- solidPng now writes RGBA channel bytes directly, removing one Buffer allocation per pixel; valid CRC32 emitted for independent PNG wire fixtures
- Removed three pure lease executions, two pure action/helper executions, duplicate approval/placement/warm-refusal cases and two image cases; exact totals in metrics
- Image owner removes 4-frame in-thread/worker relative benchmark, uses tiny actual codec fixtures and virtual default30s deadline
- Agent cancellation uses actual child readiness, default9min open wait is virtual, no arbitrary time polling added

Actual child termination, Worker startup, HTTP/WebSocket relay and the100ms MJPEG pipeline remain because fake unit work cannot verify these boundaries. Baseline/final timing is centrally coordinated; this report claims no unmeasured speedup.
