- No new production injection hook. Public KnowledgeSearch constructor receives external embedder fixture with fixed 2D vectors; real vector-index/BM25/fusion/MMR/bands/persistence execute.
- Model owner independently retains pinned actual Tokenizer.encode(...add_special_tokens:true) <=512 oracle. Chunk unit tests own body coverage, ordering, overlap and Unicode integrity without using production cost estimate as expected result.
- No dependency, snapshot or configuration removal in this subsystem; all remaining fixtures/helpers have surviving callers.
- No measured incoming speedup claimed; corpus5000/dimensions384/p95<300ms performance gate retained. Only redundant warmup query and unrelated graph diagnostic removed; dense fixtures reduced to sufficient multiple windows and arbitrary async polling removed.

## Validation and performance

Only static checks have run in this child: nine edited TypeScript files parse without diagnostics, and the scoped diff whitespace check passes. Runtime checks and comparable incoming measurements are pending the parent’s reserved uncontended runner. No runtime pass or speedup is claimed here.

The retained 5,000-entry / 384-dimensional hybrid search performance case protects the independently approved p95 < 300 ms budget and still includes filtering, MMR, facets, examples and paging. No arbitrary count threshold is used to remove performance coverage.

The incoming performance ID helper remapped digits to letters already in base32 (0 and a both became a), overwriting corpus records. It now keeps padded base32 IDs unchanged.
