# Daemon auth, providers, identities, previews, plugins and secret files audit

30 daemon subsystem test files outside host/MCP/boxes/profiles/workflows/knowledge/desktops/chat/root. 399 baseline static test declarations; no parameterized/dynamic declarations in scope.

Each baseline named test declaration is counted once, including a removed consolidation source and its surviving owner as separate disposition entries. Seven executions disappear; no new test declarations are added.

Disposition counts: {'KEEP': 373, 'REWRITE': 13, 'CONSOLIDATE': 6, 'OPTIMIZE': 4, 'DELETE': 3}.

Test source delta: 103 added, 198 removed, **-95 net lines**. Seven named test executions removed; no new declarations. Fourteen unused exports internalized.

## Changes and cost

- Three duplicate installer scenarios removed; both successful native package layouts and one complete generic failure matrix survive.
- Private GitHub check-summary and box-engine helper executions consolidated into public result owners. Duplicate favicon-lock fixture consolidated across two real server registrations.
- Nine duplicate child Node launches removed from preload cartesian scenarios; all entrypoint/workspace/off-record classes remain.
- Silent DNS deadlines use virtual JavaScript time after a real UDP query receipt; actual TCP refusal, pending DNS and filesystem responsiveness remain exercised.
- Mock-only containment wiring case replaced by actual outside-workspace symlink checks inside an existing git/filesystem/store workflow.
- Auth temporary directories now have teardown. Token/idle/cache oracles no longer import implementation constants; label checks retain device data without prescribing prose.
- Unused exports internalized: five GitHub TTL constants, four GitHub summary/mapping functions, two auth timing constants, two box-engine helper functions and their interface. These have no non-test external callers; implementations and production behavior are unchanged.
- Repeated plugin-catalog assertion in the service helper, duplicate route refusal probe and full git argv-array assertion removed. Catalog HTTP owner and actual git ignored-file workflow remain.

## Validation and measurement

Pending root-coordinated focused/full runs; this report does not claim unexecuted checks.

Performance numbers will be recorded after comparable runs. No CI improvement or suite speedup is inferred from removed operations. Real Chromium, real tar extraction/smoke processes, hostile parser workloads and real git/file workflows remain because the output/security contracts depend on those seams.

## Evidence model

Each file section states the independent source, oracle class, stable seam, refactor resistance and owner distinction shared by its rows. Every row names the exact baseline test, gives its disposition and credible scenario failure, and quotes an original assertion site as review evidence. The JSON companion preserves the baseline identities and file evidence and disposition reasons. Literal test fixtures and documented native protocols are the source of expected results; the assertion excerpt is evidence of the test oracle, not a production-derived specification.
