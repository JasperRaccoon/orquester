# MCP message tools — completed cleanup disposition

Pre-edit inventory: all 50 original tests in `apps/daemon/src/mcp/tools/messages.test.ts`; production owner `tools/messages.ts`, `testing.ts`, referenced history/transcript owners, root instructions, daemon scripts, and [MCP public documentation](../orquester-mcp.md) Messages/Waiting/Size plus [Goals design](../superpowers/specs/2026-09-24-agent-goals-design.md) §§5.1, 5.7, 8.6 were read. Root delegated this scope separately from the remaining MCP audit.

Isolated failure model: wrong outgoing prompt/mode/attachment reference; precondition side effects; mistaken turn identity across upload, restart or summary lag; wait spin/timeout/closure; truncated plan sent; wrong goal routing/answer correlation; invalid transcript arguments; result exceeding the public JSON byte cap. Retained tests below cover only these independently observable failures.

Every KEEP/REWRITE below satisfies the full bar as follows: **(1)** the named behavior is specified by the public MCP docs (Messages, Waiting or Size; goal cases additionally Goals §§5.1/5.7/8.6), not by private implementation comments; **(2)** the case-specific failure in the table changes the caller’s response or a daemon command; **(3)** expected values are literal protocol outcomes/data/ranges and documented byte/time bounds, with canned input events independent of the owner; **(4)** assertions invoke the registered tool’s schema/run contract through the required DaemonApi transport seam; **(5)** internal helper names, tree structure and private call counts may change without breaking these assertions; **(6)** messages.ts is the lowest owner for send/result/wait/goal routing and final envelope behavior, whereas repeated transcript/history projections are deleted in favor of their lower owner. Supplied fake frames model external daemon events; they do not implement the tool behavior being asserted.

Non-test callers: `messageTools` is registered by the MCP server/tool catalog. All helpers in messages.ts are private and called by real tool handlers; no test-only production exports or injection hooks were found. Shared fixtures/FakeDaemonApi remain used by retained MCP tests. Risk is low: protocol routing/persistence-sensitive regressions remain; redundant projections and wording/call-shape constraints are pruned.

Focused validation for every row: from `apps/daemon`, `pnpm exec node --import tsx --import ../../scripts/test/assert-ok.mjs --import ./test/quiet-mock-timers.mjs --test src/mcp/tools/messages.test.ts`. Root owns repository typecheck/test gates.
