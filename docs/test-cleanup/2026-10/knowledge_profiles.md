# Knowledge, plugins and Agent Profiles test cleanup

Audited all **45 assigned test files / 458 baseline named declarations**. One integration declaration expands across four agents. Disposition counts refer to named declarations, not runtime subtests: **12 DELETE, 39 REWRITE, 1 OPTIMIZE, 4 CONSOLIDATE, 402 KEEP**. The final scope has **442 named declarations**. Named test files changed by **+189/−444 lines (net -255)**; no test file, fixture, snapshot, dependency or required gate was removed. The shared test fixture module adds 18 lines to replace the removed production fixture hook; its filesystem setup cost is included in the required final measurements.

The baseline inventory was captured before any scope edits. Retained tests were read with their production owners and current wire/storage contracts; shared file evidence below supplies the six-bar rationale, and each row supplies its specific behavior/oracle. A missing unique contract was a deletion reason; a historical ledger/name/pattern was not used as the verdict.

## Changes and orphan cleanup

- Deleted registry/slot inventories, prompt/prose/copy change detectors, private batching/read-count tests and duplicate account/answer/workspace scenarios. Preserved concrete security, persistence, protocol, account-isolation, error handling and critical launch/tool workflows.
- Replaced the simulated offline check with actual execution of the shipped Python smoke script. Tokenizer/dependency shims isolate external packages; they leave the downloader enabled. The script must reach tokenization, refuse, identify the missing fixture resource, and never emit the downloader marker. This can fail when the production offline guard is removed.
- Replaced the POSIX 40,000-record race fixture with a real FIFO that holds the older JSONL read until a newer graph publishes. This controls completion order without a production injection hook. Windows keeps the prior regular-file scenario because POSIX FIFOs are unavailable there.
- Moved private slug fallback/collision protection into real Claude preparation, source-file mapping into real graph JSONL loading, file permissions into actual preload execution, malformed cache recovery into VectorCache, and workspace-event silence into actual workspace routes.
- Removed the private profile-read counter from the KnowledgeService harness. Internalized 17 exports with no external production consumers after repository-wide searches: indexer instruction text; worker-count helper and normalization cap; graph source-file/snapshot helpers; host preload renderer; four preparer version constants; Claude plugin slug helper; Codex Global config path helper; installer smoke timeout, manifest filename, uv environment, minor-line predicate and lock filter. Runtime algorithms/values are unchanged. Removed `KnowledgeGraph.replace`, a production method whose only callers were tests; retained fixtures now write small temporary JSONL files and call the real `load` boundary through one shared test-only helper.
