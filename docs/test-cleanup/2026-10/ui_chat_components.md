Scope: all **64** files assigned to `ui_chat_components`: **607 named test declarations** (parameterized declarations counted once), plus the standalone scenarios in three `.check.ts` scripts. All assigned test bodies and direct production owners were reviewed. The root lexical inventory additionally mistook six `RegExp.test(...)` calls for tests; they are assertions in the composer render script, not declarations.

Named declaration dispositions: **{'KEEP': 504, 'REWRITE': 30, 'CONSOLIDATE': 3, 'DELETE': 69, 'OPTIMIZE': 1}**. Baseline test/check LOC: **11386**; final: **10430**; net: **-956**. No snapshots, fixture files, dependencies or runner configurations are removed in this scope. Dead production `lib/render-probe.ts`, all six `noteRender` call sites, the `hasClosingLine` convenience wrapper, exported quote-ID generator, loaded ToolsChip view export, helper-only math/image exports and the image-codec injection argument are removed/internalized. The encoded-image/browser dependency isolation stays in tests through standard browser APIs.

The test-by-test table records the original declaration names, including names changed during rewrites. A `CONSOLIDATE` row explicitly identifies whether its owner survives. Large literal parameter tables remain in their source files; a row represents that declaration and all its vectors, not one fabricated runtime case count.

## Behavioral evidence applying to every retained row

1. **Independent contract**: each file below identifies the repository specification, API/wire/storage/browser format, security obligation or credible historical workflow regression. A current implementation comment alone was not used to retain a private call count or a known bug.
2. **Real failure**: the original case title describes the concrete user/caller failure, and its literal oracle excerpt shows what must disagree for that regression. Rewrites fix cases whose original assertions never observed the claimed submission/path/failure reason.
3. **Independent oracle**: retained assertions compare supplied authored bytes, fixed provider fixtures, literal state/command/URL results, actual storage bytes or browser-observable results. Paired quote serialization/parser and URL-filter self-oracles were replaced with literal inputs/outputs. Options-object and cache-identity assertions were removed.
4. **Stable seam**: retained tests use production-facing pure decision/serialization functions, component event/callback/DOM accessibility surfaces, storage bytes, browser API boundaries or protocol frames. Private render instrumentation, CSS-coordinate and source/import scans are removed.
5. **Refactor resistance**: expected user data, command payloads, security refusal, selection/copy results and state transitions survive identifier changes, component extraction and private algorithm changes. No remaining test in this scope requires a specific component name/render frequency, private key/hash value, source import path inventory or toolbar pixel position.
6. **Unique protection**: each file rationale below compares its owner to the nearest remaining layers. Model/serialization tests own differing input/output policy; DOM/entry tests remain only where event routing, lifecycle, provider-context wiring or wire consumption adds a distinct failure mode. The API owner specifically confirmed that the composer model descriptor/read cases have no exact API duplicate.

Non-test caller review used repository-wide searches before removing exports: ChatComposer/AgentChatView and timeline/message row consumers use the retained modules in both shared UI entry points. `countRenders` had only the deleted test consumer; `noteRender` calls were instrumentation alone. Internalized image helpers and math lookahead/guard helpers have only same-module feature callers. `ToolsChipView` remains a local component used by `ToolsChip`; quote IDs remain generated internally. Public transport/package APIs are unchanged.
