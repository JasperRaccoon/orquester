All 330 original named test families are dispositioned below: 62 DELETE, 89 REWRITE, 179 KEEP; parameter expansion leaves 279 passing runtime cases. This ledger was recorded before test edits, with subsequent decisions appended before each follow-up edit; original line numbers identify the original cases. Default disposition is DELETE. Retention below applies only to observable behavior, not helper shape, prose, layout, catalogue inventories, or fake-owned behavior. Parameterized titles denote all parameters under that case family.
