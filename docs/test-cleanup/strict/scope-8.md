# Grok adapter strict test cleanup (scope 8)

Audit ledger created before test edits. Immutable baseline: `/tmp/orquester-test-audit/baseline`; current unmodified Grok suite: 369/369 pass (366 declarations, parameterized cases expand at runtime).

## Six-bar method and risk

Every KEEP/REWRITE row inherits: (1) its file source below is external to the owner implementation, (2) its named wrong caller-visible outcome is a distinct regression, (3) fixed expected protocol/event/response values come from that source or an explicitly stated API contract rather than being computed from the owner, (4) the file seam below is an adapter API, wire response, durable RuntimeEvent, or converter immediately used by those surfaces, (5) the assertion remains meaningful after internal refactoring of the owner, and (6) the row selects the lowest seam that can observe that particular failure; replay/lifecycle cases remain where frame routing, process order, or persistence cannot be checked by a helper. A row describing only internal shape or duplicate coverage is DELETE.

The provider fixtures are redacted observations, not mutable golden outputs. Risk is concentrated on rejecting useful regression cases; keep captured protocol, session ordering, account and secret behavior. No test-only production export was identified from caller searches. Focused validation: `node --import tsx --import ../../scripts/test/assert-ok.mjs --import ./test/quiet-mock-timers.mjs --test --test-concurrency=2 $(sed 's@^apps/daemon/@@' /tmp/orquester-test-audit/scope-8.txt)` from `apps/daemon`. Full gates belong to root.

The isolated units have concrete failure paths: ACP can correlate a reply to the wrong request, hang a parked call, leak a secret, or select an interactive login; converters can approve the wrong operation, misread a captured provider field, lose a proposal, invent usage, or flood the event bus; the normalizer can merge parent and child rows, duplicate an end, drop a late frame, or leave background work marked live; the history projection can replay old work as live or charge it again. Cases below survive only where their assertions reach the corresponding wire/event/API outcome. The uncaptured alternate frame orders removed below lack that independent source.
