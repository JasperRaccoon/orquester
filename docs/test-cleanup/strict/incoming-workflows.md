## Evidence and six-bar interpretation

The report uses these independent sources, read alongside the owners rather than treating implementation as its own specification:

- **P — captured provider protocol:** `apps/daemon/test/fixtures/claude/README.md`, observation 24a–e, and `17-workflow.ndjson`, `18-workflow-stop.ndjson`, `19-workflow-tools.ndjson` with their redacted disk sidecars. CLI 2.1.285 / SDK 0.3.278 captures specify asynchronous launch handles, one provider task per run, phase/slot identity, member sidecar conversations, and killed/stopped control outcomes. Sidecar content/prompt text is provider data, not application UI copy.
- **G — public runtime and GUI contracts:** `docs/superpowers/specs/2026-09-21-agent-chat-gui-design.md` §§4.1, 4.2, 4.5, 6.2 and 7.6; shared runtime task status/linkage/attempt types in `packages/api/src/agent-chat`; member-owned drill-ins, verbatim launch prompts, stable lifecycle identity, grouped members and liveness. A phase/member/usage count is domain data; HTML row counts and formatting prose are not independent contracts.
- **S — per-task Stop API:** `docs/orquester-mcp.md` §6 stop_task and `packages/api/src/agent-chat/{wire,adapter-types,adapter}.ts`: accepted request differs from terminal outcome, capability-gated action, live workflow/subagent/shell targets, no independently stoppable workflow members/drivers, command receipt idempotency and typed failure activity. `targetTaskId` is deliberately distinct from activity ownership `taskId`.
- **M — public MCP reads:** `docs/orquester-mcp.md` §§3, 4, 6 and 7: own-agent selection, invalid selector error, bounded text/UTF-8 results, parent anchors, subagent details. Public schema/returned fields are stable seams even when the prose schema has not yet listed every newly introduced Workflow field.
- **X — security:** repository AGENTS.md account/path containment and keeping host-only data off client responses; untrusted provider/journal file identifiers cannot disclose unrelated files. A negative test requires a readable forbidden sentinel, not a missing target or log message alone.

For **each KEEP and REWRITE row**, its first evidence cell identifies **bar 1** independent source and exact contract, **bar 2** the recognizable incorrect output/state it would expose, and **bar 3** the literal capture/input/domain outcome used as oracle. Its final cell assigns **bar 6** the unique lowest stable coverage owner and excludes overlap. **Bar 4** is the production-consumed seam in the table below; **bar 5** is satisfied only by asserting its public data/state/protocol outcomes, independent of helper names, internal callback shape, Promise/array identity, generated IDs, markup layout and incidental copy. REWRITE means the incoming form fails one or more bars and survives only in the narrowed stated form. DELETE is the default whenever no unique independent contract remains. No test is kept for counts or coverage.
