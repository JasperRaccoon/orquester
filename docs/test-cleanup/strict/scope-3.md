# Strict cleanup: UI agent-chat logic (scope 3)

Completed cleanup: 288 original declarations audited; 50 DELETE, 10 REWRITE, 228 KEEP; 238 cases remain. Dispositions and failure/oracle analysis were recorded before editing tests; validation results are appended after execution.

## Shared six-bar rationale

For each retained or rewritten case below: **1** the named independent design/protocol/storage/regression source specifies the listed behavior; **2** the concrete failure is loss, corruption, misrouting, inaccessible action, or false status described in its oracle; **3** expected ids, bytes, states and durations are fixed test data, not computed by the owner under test (the command-output exception is explicitly rewritten); **4** the listed production-consumed parser, projection, state-machine or hook is the seam; **5** assertions concern resulting data/state, not source text, private calls, memo identity or DOM/CSS; **6** the file owns the distinct transformation listed for each case. Shared API tests own provider normalization/folding, not UI selection; UI component tests own rendering/actions, not these derivations. Extra-layer duplicates identified below are deleted.

Risk: retained timeline/history cases protect transcript visibility and rewind safety, so deletion is limited to duplicated ownership or no independent behavioral oracle. No runtime behavior is changed. No live daemon/browser is started.

Focused command (package directory): `node --import tsx --import ../../scripts/test/assert-ok.mjs --import ./test/svg-loader.mjs --import ./test/quiet-mock-timers.mjs --test --test-concurrency=2 <remaining scope-3 paths>`. Root owns repository check/test/build gates.
