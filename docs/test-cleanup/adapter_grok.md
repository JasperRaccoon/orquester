Validation for every disposition: from apps/daemon, `node --import tsx --import ../../scripts/test/assert-ok.mjs --import ./test/quiet-mock-timers.mjs --test <remaining assigned Grok *.test.ts files>`. Parent runs repository pnpm check/test gates. Risk for deleted cases: low where duplicate or nonbehavioral; security/protocol cases retain their independently meaningful owner. Retained/reworked cases exercise untrusted protocol inputs and asynchronous ownership, so focused runtime validation is required.

The following six-bar justifications apply to every KEEP/REWRITE row in that file, with each row naming the distinct input/state and expected caller-visible result. B1 identifies the independent source; B2 is the concrete behavior named in the row (its violation is the detected failure); B3 uses captured inputs, external protocol/data expectations, or independently specified state transitions, never a value calculated by the owner; B4 names the production-facing seam; B5 allows internal factoring/renaming changes because only output, persisted bytes, errors, process state or protocol replies are asserted; B6 retains the lowest owner that can observe that row’s state transition. Higher-level overlap is deleted unless it proves actual adapter registration/ordering or ingestion/liveness ownership that the lower mapping seam cannot observe. A row marked REWRITE is subject to these statements after the recorded rewrite.
