# Agent-host index test cleanup

Disposition ledger recorded before test or production edits. Baseline: 123 tests pass (17 suites), command below. Scope: the four index test files and their local owners/support. This is an implemented cleanup, with completion and validation appended after changes.

## Independent contracts and six-bar justification

The independent sources are root AGENTS.md (durable append-only event log, untrusted cache rebuild, sequence ordering, protocol safety), agent-host README.md index module map and History/Search behavior, shared API agent-chat search/history/prompt wire types and limits, and persisted schema migration compatibility documented in schema.ts. Public callers are orchestration/orchestrator.ts and host services: boot catchUp/observe/stop, readHistory, search, listPrompts/readPrompt and rewind guards. These callers consume ThreadIndex, not private resident IDs, SQL query strings, cursor helpers or table inventories.

Every KEEP/REWRITE row below incorporates B1–B6 here AND its specific failure/expected result in the row. B1: its concrete log/storage/query outcome is specified by the listed independent contract, not an implementation declaration or copy. B2: the row states the missing/wrong history, search, prompt, recovery or security result a host caller would observe. B3: retained expectations are literal IDs, text, booleans, independently serialized fixture log byte offsets, filesystem modes or documented API limits; no expected result comes from an index/fold reference implementation. B4: setup feeds durable-event fixtures through public ThreadIndex; assertions use its caller contract, filesystem mode or file lifecycle. Corruption setup deliberately edits persisted cache bytes as the storage/migration seam, not collaborator calls. B5: SQL, queue, cache and helper identifier refactors may change implementation without changing these outcomes; version-specific storage corruption fixtures only encode the persisted format being tested. B6: this real SQLite owner seam is the lowest stable seam combining event application and durable index reads. Host orchestration tests own store/route integration and failure mapping; these cases own the underlying real SQLite outcomes, and API reducer tests do not own derived index persistence. Cases at the same seam are distinguished by the row’s failure trigger; duplicate/private-only cases are deleted.

Isolated unit failure modes considered: dropped/reordered log events; cursor advanced despite rollback; stale/revoked data surviving recovery; incomplete streamed text; missed opening prompts/checkpoints; cross-compaction rewind; cross-project/subagent leakage; unsafe FTS syntax; pagination omission/duplication; corrupt/old cache accepted; loose file permissions; shutdown writes lost. No isolated pure helper tests survive.

Risk: storage/history/query contracts are sensitive; retained regressions run against real SQLite. Deletions lose only private shape/parity/copy checks or explicit duplicates. Every row uses focused validation V1; root owns repository gates.

V1 (cwd apps/daemon): `node --import tsx --import ../../scripts/test/assert-ok.mjs --import ./test/quiet-mock-timers.mjs --test src/agent-host/index/*.test.ts`. Follow with daemon typecheck and scoped `git diff --check`.

## Caller/seam inventory before edits

- ThreadIndex methods are production callers’ service contract (orchestrator.ts); keep the methods and real event fixtures. TestLog models actual UTF-8 NDJSON positions, not expected query results.
- `residentThreadIds` is referenced only by indexer.test.ts: remove the method/exported inspection surface. `MAX_RESIDENT_THREADS` has no non-test external consumer: make private.
- `INDEX_CATCH_UP_CHUNK`, cursor encode/decode helpers, `toFtsQuery`, `clampPromptsLimit`, prompt scan constants and PromptSource have no non-test external consumers: make private once focused tests stop importing them.
- ThreadIndexOptions.driver has no production caller; remove the injection option and instrumentedDriver test helper after converting error tests to actual locked/colliding files. sqlite.ts’s actual driver abstraction remains required by the production database lifecycle.
- `capText`, `readPromptsPage` and PromptCandidate are additionally imported by orchestration/testing/fake-index.ts. Coordinate with that owner; do not break its shared fixture.
- Remove same-implementation reference indexes, foldedPromptIds, internal table inspection helpers and serialized pending-state assertion scaffolding when unused.
