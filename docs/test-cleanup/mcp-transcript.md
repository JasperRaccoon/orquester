## Independent contracts and full retention bar

Sources: `docs/superpowers/specs/2026-09-22-orquester-mcp-v2-design.md` §§6.2, 7.2, 7.6 (public transcript, output drill-in, UTF-8 whole-result budget, explicit 320-byte hint reserve, omission markers and paging); `docs/orquester-mcp.md` (public caller usage); persisted agent-chat domain-event/snapshot protocol and GUI contracts for ownership, commentary, goals and rewind. A field's fixture text is passthrough data, not frozen UI prose. No expected projection may be produced by a second invocation of the owner.

Each retained row below specifies its distinct failure and expected behavior and applies all six numbered points of its group:

- **P — projection:** (1) the public TranscriptEntry/§7.6 field/visibility contract, with independently authored domain records; (2) missing/wrong kind, severity, ownership, actionability or data is visible to read_transcript callers; (3) expected literals/fixture data are authored independently, never read from implementation output; (4) transcriptEntries is the production snapshot-to-public-result seam; (5) tests do not inspect source, caches, collaborator calls, identity or key order and tolerate internal refactors; (6) shared API tests parse/fold records but cannot detect MCP projection errors, and tool-level routing does not own this matrix.
- **B — budget:** (1) §7.6 specifies whole JSON UTF-8 byte cap, 320-byte hint reserve, priority and preserved newest answer/list summaries; (2) omitted reply, misleading file totals, missing live roster, malformed Unicode or oversized response fails caller use; (3) size uses language-standard JSON.stringify/Buffer and independently stated limits, expected text/IDs/files come from authored fixtures; (4) transcriptEntries owns public budgeting; (5) no private allocator, cache, export or traversal shape asserted; (6) this is the lowest owner combining entries and roster, whereas result.ts only caps generic payloads and messages routing tests own hint composition. Retained cases each target a distinct listed boundary, not random duplicate scenarios.
- **H — history:** (1) §7.6 defines beforeTurn/coveredTurns/olderTurns, persisted userMessageId association and retained-window actionability; (2) skipped turns, lost prompt/failure, false coverage or stale plan action becomes caller-visible; (3) literal authored turn/message IDs, times and expected ranges define the answer; (4) transcriptEntries over snapshots/merged pages is stable production interface; (5) no fold storage/cache identities or private range calls are tested; (6) history loader tests fetch records, API fold tests own record state, neither owns the MCP selected/paginated projection.
- **O — output navigation:** (1) §§7.2/7.6 specify outputItemId, command versus file stream, retained/legacy ownership and read_tool_output navigation; (2) wrong/missing ID offers unreadable or another agent's output, or a ghost call; (3) IDs/status/commands are authored fixture facts, not outputs from helper under test; (4) transcriptEntries is public projection owner; (5) no private grouping implementation or helper shape asserted; (6) API command-output tests own format decoding and fold tests own retention; these cases keep only MCP grouping/navigation/scope behavior. Full-output transport tool tests do not decide which transcript row advertises its ID.
- **C — byte cut:** (1) the shared cutTail production contract implements §6.2/§7.6 exact JSON-byte, whole-code-point trimming, independent ECMAScript JSON/UTF-8 encoding; (2) wrong saved size creates oversized results or unnecessarily removes caller text; (3) JSON.stringify/Buffer oracle is independent of hand-coded byte logic; (4) cutTail is shared by production views.ts and transcript fitting, a stable lowest seam; (5) only input/output text/byte facts asserted, no scanning algorithm/calls; (6) no stronger owner exhausts escaped controls and lone surrogates. Before retaining this isolated unit, failure modes are: wrong escaped/control byte count, splitting surrogate pair, cutting on nonpositive need, insufficient bytes saved, or removing more code points than required. The retained case tests only those failures.

Production caller audit before removal: `transcriptEntries` is called by `tools/messages.ts`; `transcriptRange` also by messages; `itemTurnId` by history; `proposedPlan` by views/messages; `cutTail`, `fitRoster`, `sized`, `SUBAGENT_TEXT_CHARS` by views. `fitEntries`, `jsonTextBytes`, `ROSTER_SHARE` have no non-test external callers and will become private. `TRANSCRIPT_HINT_BYTES` has only transcript and a messages test consumer; MCP owner confirmed that redundant reserve test/import is being deleted, so it becomes private. No public package API exports these internals. Shared fixtures.ts remains required by other MCP tests.

Risk: low for deletion of private/change-detector/duplicate coverage; keep real protocol regressions and use authored boundary expectations before deleting replay comparisons. Production changes are export visibility only. Full MCP/tool/integration/typecheck gates are coordinated by root; this scope runs the smallest suite with existing package import hooks.

Validation command (cwd `apps/daemon`): `node --import tsx --import ../../scripts/test/assert-ok.mjs --import ./test/quiet-mock-timers.mjs --test src/mcp/transcript.test.ts`.
