# Daemon chat summary and routes cleanup

Status: completed cleanup. All 73 original named cases are dispositioned: 9 DELETE, 37 REWRITE, 27 KEEP. The 64 surviving cases pass focused validation. Scope: `summary.test.ts` (41 original) and `proxy-routes.test.ts` (32 original).

## Independent contracts and six-bar records

S — Summary polling boundary. (1) [Agent chat design §6.4](../superpowers/specs/2026-09-21-agent-chat-gui-design.md), [MCP v2 §9.2](../superpowers/specs/2026-09-22-orquester-mcp-v2-design.md), goals §§4.7/5.5, and AGENTS.md tolerant cross-process validation independently specify the coarse events, attention cursor, push transitions, goal and background-work semantics. (2) Each case below names the distinct visible tab, notification, waiter, usage, or supervisor failure. (3) Expected stamps, public payloads and state transitions are literal scenario data, never computed by the production reducer/parser. (4) Rewrites deliver JSON through a real temporary Unix HTTP socket, invoke the production poll entry point, and read ChatSessionManager summaries, public events/push delivery or supervisor callbacks. (5) No assertions require a parser name, private method, map layout, collaborator count or timing override. (6) This service is the lowest owner of poll-to-tab/bus/push/cursor transitions; activity-ladder tests own pure ranking, supervisor tests own restart execution, and MCP tests own consumption. Their narrower contracts cannot catch omission/miswiring here. Every retained S row uses this record plus its distinct failure below.

P — Daemon transport boundary. (1) Agent chat design §§6.2–6.4, thread-index/lazy-boot design and the shared API wire types specify HTTP paths, statuses, encoded IDs, authenticated host hops and cursor ownership. (2) Each row names a caller-visible protocol or lifecycle failure. (3) Expected upstream paths/statuses/payloads are explicit fixture bytes or independent status tables; a fake host only serves/transparently records transport and does not implement proxy behavior. (4) Fastify HTTP injection plus a real temporary host socket observes the public transport; streaming additionally uses a real temporary TCP connection. Lifecycle callbacks are production seams declared by AgentChatRouteDeps. (5) Assertions survive handler/helper/identifier refactors and do not count private wrappers. (6) The daemon proxy is the lowest owner of translating transports, gating tabs/host health and choosing passthrough versus older-host fallbacks. Host service, API route-builder and MCP consumer tests cannot detect a broken hop. Every retained P row uses this record plus its distinct failure below.

Failure modes were enumerated before retaining isolated behavior: lost/misclassified state, stale or repeated attention cursor, unwanted/missing push, stale pending cards, stale usage, missed drain wake; bad route/auth/query/body/status forwarding, malformed response leakage, lost reconnect sequence, broken stream cancellation, and incorrect compatibility fallback.

Non-test callers: `agent-chat/service.ts` constructs and runs AgentChatSummaryService, reads its background-work/poll readiness and calls stopAndWait; `index.ts`/service route wiring supplies AgentChatRouteDeps. `applyFields`, `applyUsageLimits`, exported sanitize helpers, summary interval/timeout exports and interval injection callbacks have no outside production callers; privatize/remove them. The clock injection also has no production caller and can use native Date mocking. Retain actual supervisor/usage callbacks and stopAndWait because service.ts needs them.

Validation for every row: from `apps/daemon`, `node --import tsx --import ../../scripts/test/assert-ok.mjs --import ./test/quiet-mock-timers.mjs --test src/agent-chat/summary.test.ts src/agent-chat/proxy-routes.test.ts`. Risk for S rewrites is losing a transition while changing the test boundary; assert the same literal external result. Risk for P rewrites is losing a path/status branch; preserve explicitly named contracts. Delete rows have low risk for the stated remaining owner/duplicate reason.
